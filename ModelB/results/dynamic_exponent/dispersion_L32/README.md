# L=32 Model B 色散

参数为二维 `lambda=1`、无固定 \(M=0\) 约束的 canonical 初态、内部
SOSRA 步长 `dt=0.005`。每条 Model B 轨迹守恒自己的初始总磁化，但
ensemble 中的总磁化按 canonical 分布涨落。
横轴统一使用格点动量
\(\hat k^2=\sum_\mu4\sin^2(k_\mu/2)\)，弛豫时间定义为归一化相关函数
首次到达 \(1/e\) 的对数插值时间。本分析不由不同 \(L\) 的 FSS 拟合 \(z\)。

## 两个温度点

真临界点采用大尺寸 Binder crossing 给出的
\(\kappa_c=0.34034(8)\)。L=32 初态的独立检查为
\(U_4=0.6094(52)\)，与周期方格 2D Ising 临界值约 0.6107 相容。

赝临界点用
\[
\chi_{|m|}=L^2\left(\langle m^2\rangle-\langle|m|\rangle^2\right)
\]
定义。直接扫描 `kappa=0.3325:0.0005:0.3370`，每点 65536 个
Wolff+FAHMC 样本；\(|m|\) 的最大积分自相关时间为 2.38，bootstrap
block size 为 512。3、5、7 点二次拟合分别给
0.334237、0.334086、0.334254，因此采用
\[
\kappa_\chi(L=32)=0.33425(24),
\]
其中统计误差 0.000163，拟合窗变化 0.000169，括号内为二者平方和。
原始扫描为 `pseudocritical_scan_fine.jld2`，最终表、图和拟合参数为
`pseudocritical_scan.tsv`、`pseudocritical_scan.pdf`、
`pseudocritical.json`。

## 结果

真临界结果在 `critical/`，赝临界结果在 `pseudocritical_t6000/`。
两个目录都包含 `tau_k.tsv`、`tau_k_axial.pdf`、
`tau_k_diag.pdf` 和最低模的 `tmax_stability.tsv`：

| 点 | \(\tau_{\rm axial}(n=1)\) | \(\tau_{\rm diag}(n=1)\) |
|---|---:|---:|
| \(\kappa_c\) | 655(45) | 195.1(8.1) |
| \(\kappa_\chi\) | 876.5(25.5) | 241.1(3.9) |

赝临界点相对真临界点的比值为 1.34(10) 和 1.236(55)；高动量端的
比值约 1.08。赝临界峰位不确定度尚未传播进这些动力学误差。

轴向平均 `(n,0)` 与 `(0,n)`；负动量由实场的共轭约束重复。对角平均
`(n,n)` 与 `(n,-n)`，同样穷尽四个对角方向的独立信息。

## 时间分辨率

这里的 `1` 是粗文件的保存间隔 `sample_dt`，不是积分步长。把同一批
`sample_dt=0.1` 轨迹降采样到 1 后，所有 \(\tau\ge3\) 的模式变化不超过
0.36%；但轴向 \(\tau=0.60,0.39\) 的模式会分别偏高约 13% 和 25%。
分析程序因此只允许粗文件贡献 \(\tau\ge3\,sample_dt\) 的点，高动量点只取
细采样文件。

真临界最低模的粗批前缀检查为：

| `tmax` | 2000 | 2500 | 3000 |
|---:|---:|---:|---:|
| 轴向 \(\tau_{1/e}\) | 671(58) | 646(49) | 636(47) |
| 轴向 \(C(t_{\max}/2)\) | 0.264 | 0.203 | 0.167 |
| 对角 \(\tau_{1/e}\) | 188.6(9.7) | 189.9(9.2) | 193.1(8.6) |

所有窗口均有 400/400 个 bootstrap 样本越过 \(1/e\)，不同 `tmax`
的变化在统计误差内。表中是粗批结果；上面的最终值还按误差合并了细批。

赝临界最低轴向模的粗批同轨迹前缀截断检查为：

| `tmax` | 2000 | 2500 | 3000 | 4000 | 5000 | 6000 |
|---:|---:|---:|---:|---:|---:|---:|
| \(\tau_{1/e}\) | 890(40) | 880(35) | 886(30) | 888(29) | 884(27) | 886(25) |
| \(C(t_{\max}/2)\) | 0.332 | 0.256 | 0.201 | 0.130 | 0.081 | 0.061 |

`tmax=2000` 时只有 393/400 个 bootstrap 样本在最大 lag 内越过
\(1/e\)；从 2500 起为 400/400。前半段 `[0,3000]` 与后半段
`[3000,6000]` 分别给轴向 886(31)、880(36)，对角 240.9(4.8)、
242.8(5.3)，彼此相容。完整数据已经把最低轴向模追踪到 \(C=0.061\)，
所以 `tmax` 不再是当前 \(\tau_{1/e}\) 的可见系统误差；若要正式报告
\(\tau_{\rm int}\)，仍需另行规定尾部截断或拟合方案。完整数值在
`pseudocritical_t6000/tmax_stability.tsv`。
