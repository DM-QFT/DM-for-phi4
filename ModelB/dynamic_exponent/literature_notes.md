# 文献方法与代码审阅

## Chattopadhyay et al., Phys. Rev. D 108, 074004 (2023)

论文：[arXiv:2304.07279](https://arxiv.org/abs/2304.07279)，
[DOI](https://doi.org/10.1103/PhysRevD.108.074004)。
配套代码位于 `references/chattopadhyay-modelB`。
该仓库当前没有显式 `LICENSE` 文件，适合核对和参考算法；若要直接复制或发布
其中代码，应先向作者确认授权。

### 论文和源码中的实际流程

- 三维单分量 `ϕ⁴`，`λ=4, T=Γ=1`，临界裸质量
  `m_c²=-2.28587(7)`。
- 每次 proposal 在相邻格点间交换
  `q=sqrt(2 Γ Δt) ξ`，所以总电荷逐次更新都严格守恒；接受率为
  `min(1, exp(-ΔH/T))`。
- 每个空间方向使用四重 checkerboard。一个完整三维 sweep 是
  `4 offsets × 3 directions = 12` 次可并行 GPU kernel。
- 源码使用 `Δt=0.04`。Metropolis 接受步骤使有限 `Δt` 下的平衡分布仍满足
  detailed balance；真实扩散方程则只在小 `Δt` 极限恢复。对普适指数而言，
  有限步长首先改变非普适时间单位，但仍应做步长收敛检查。
- 初始场通过 `ϕ -= shuffle(ϕ)` 构造严格零总电荷，再用同一守恒动力学热化。
- 临界指数使用 `L=8,12,16,24`。每次只分析最低非零动量
  `k=(2π/L,0,0)`，先拟合 `G(t,k) ~ exp(-t/τ_L)`，再拟合
  `τ_L ~ L^z`，得到 `z=3.972(2)`。
- 生产源码每 10 sweeps 保存一次最低轴向模；因为每 sweep 对应
  `Δt=0.04`，观测间隔为 `0.4`。每段记录约 `L⁴` 个时刻，相关函数对段内
  多个时间原点平均，bootstrap 则以不同输出文件为 block。

### 值得直接借鉴的改进

1. **有限尺寸最低模拟合。** 每个数据点都处于相同的红外位置
   `kL=2π`，比单个格点上混合不同 `ka` 的动量拟合更容易控制格点修正。
2. **守恒量由更新结构保证。** 邻格点 flux proposal 不需要在一步之后再投影
   总电荷，也不会因导数噪声离散化破坏守恒。
3. **checkerboard 并行。** 不相互作用的 link 集合可同时更新，适合 GPU。
4. **有限步长仍有正确静态分布。** 这很适合作为现有 SOSRA 动力学的独立
   交叉检查。
5. **时间原点平均与独立 block bootstrap。** 长轨迹内部的全部时间原点用于
   相关函数，误差估计则不能把这些相关的时间原点误当成独立样本。

### 当前项目相对论文可以进一步改善的地方

- 当前已有 Wolff + Fourier-accelerated HMC 临界构型，可直接开始真实时间
  演化，避免用 Model B 本身支付约 `L^z` 的热化代价。
- 但论文固定总电荷为零；普通 HMC 初态混合不同总磁化 sector。直接使用这种
  正则混合是平稳的，但有限尺寸 scaling function 与固定 `M=0` 不同，需把
  sector 选择列为系统检查。
- 只保存所需低动量模。论文公开 CUDA 程序在观测时调用完整三维 FFT；本目录
  采用 GPU 平面和加最低模正余弦投影。
- 对 `τ` 和 `z` 做整条分析链的 ensemble bootstrap，并报告拟合窗口、删去
  最小尺寸以及 `κ_c`、`dt` 的系统变化。
- 配套 `dynamic_exp.jl` 的最终 `z` 拟合没有使用相关函数的误差或 `τ` 的
  权重；其中 `τ_err` 也没有从衰减率按 `σ_τ=σ_a/a²` 传播，而且最终未使用。
  因此论文的 `(2)` 更接近删去 `L=8` 后的稳定性估计，不应当视为覆盖所有
  系统误差。我们的目标应是同时给统计误差和分析选择造成的系统包络。

## Schweitzer, Schlichting, von Smekal, NPB 984, 115944 (2022)

论文：[arXiv:2110.01696](https://arxiv.org/abs/2110.01696)；
公开代码位于 `references/phi4lattice`。
该仓库附带 GNU AGPLv3 许可证。

这是用户提到的现代 `2+1D` 标量实时模拟和 `1024²` 格点来源。它并没有保存
`1024² × Ntime` 的完整历史：

- 经典统计场论在 GPU 上局域演化，活跃场和少量工作区常驻显存；
- 每个输出时刻先把二维场沿一个方向求和，再只对长度 `L` 的数组做一维
  cuFFT，输出指定的有限动量模；
- `--maxp` 限制保存的动量数，输出间隔通常为 1，而内部再细分为 160 步；
- 不同初态/噪声 realization 作为独立作业并行，而不是把巨大的 ensemble
  全部塞进单次输出；
- 论文在小阻尼时使用 `1024²`，典型实时长度约 `10⁴–10⁵`。

他们主要在一个大尺寸上由 `τ(k) ~ k^{-z}` 提取指数。对当前项目，建议把它
作为第二条交叉检查；主结果优先采用 Chattopadhyay 的多尺寸 `k_min` 方法。
