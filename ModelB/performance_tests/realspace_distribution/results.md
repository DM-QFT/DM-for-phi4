# 实空间有限时间分布测试结果

测试日期：2026-07-26。环境为 Miyabi-G GH200、Julia 1.12.6、
CUDA.jl 6.2.0。`solver/` 与 `references/` 未修改。

## 结论

如果目标是每个有限物理时刻的分布，而不只是平衡态，不能把当前动力学替换
成 lattice Fourier acceleration、Kawasaki sweep 或辅助动量动力学。本测试
只改变时间积分公式或 `dt`，空间漂移和守恒 link noise 与生产 solver 完全
相同。

在这组 `L=32, κ=0.28, λ=0.022, T=γ=1, t≤10` 数据上：

- 当前 `SOSRA, dt=0.002` 的逐时统计与细参考的独立采样噪声相当。
- 实空间 stochastic Heun 在 `dt=0.002` 也处于采样噪声量级，计算同一
  `t=10` 约快 `1.70×`。这是目前最稳妥的低 stage 候选，但还没有修改
  solver。
- `SOSRA, dt=0.005` 约快 `2.49×`，六维联合距离仍在噪声底附近；不过
  action-density 均值在个别时刻已有约 `0.06σ` 的系统偏移。若逐时分布要求
  严格，不能只凭联合汇总就直接采用。
- `Heun, dt=0.005` 约快 `4.23×`，联合距离仅略高于噪声底，但
  action-density 的最大偏移约 `0.08σ`，已经可以检测到。
- Euler--Maruyama 即使使用 `dt=0.002` 也不适合这个目标。它虽然约快
  `2.56×`，但 action-density Wasserstein 误差约为噪声底的十倍，六维联合
  误差约为噪声底的四至六倍。大步长 Heun 和 SOSRA 也逐渐出现同类可辨误差。

因此，若以后允许修改 solver，优先进一步验证 `Heun, dt=0.002`；若只改变
运行参数，优先对 `SOSRA, dt=0.005` 做更严格的全场或训练目标验证。对于
逐时分布敏感的生产数据，当前结果不支持 Euler，也不支持 `dt≥0.01` 的
Heun；`SOSRA, dt≥0.01` 同样已超出本测试的采样噪声底。

## 测试设置

直接读取现有的 5120 个 HMC 初态和 5120 个 Gaussian 初态。每个方法从同一
组初态出发，使用独立 Philox noise，在 `t=0:0.1:10` 的 101 个共同物理时刻
取样。

细参考是两份独立的 `SOSRA, dt=0.0005`：

- `reference_a` 是所有误差的基准；
- `reference_b` 与它的差异估计 5120 个样本下的随机噪声底。

测试的逐配置实空间统计量为：

1. 守恒均值 `M`；
2. 固定格点的 `ϕ`；
3. 空间平均 `ϕ²`；
4. 空间平均 `ϕ⁴`；
5. 最近邻相关；
6. 作用量密度。

每个标量使用 KS 距离以及除以参考标准差的一维 Wasserstein-1 距离。联合
距离是在标准化后的六维统计量上取 16 个固定随机投影的平均
Wasserstein-1。整个演化和观测归约都在实空间完成；没有 FFT 或谱推进。

## 逐时联合分布与速度

下表的联合距离先对 `t=0.1:0.1:10` 取时间平均。斜线前后分别为 HMC 和
Gaussian 初态；噪声底是两份细参考之间的距离。

| 方法 | `dt` | `t=10` 加速比 | 平均联合距离 | 最大联合距离 | action-density 平均 W1 |
|---|---:|---:|---:|---:|---:|
| 细参考 B | 0.0005 | — | 0.0166 / 0.0243 | 0.0238 / 0.0419 | 0.0235 / 0.0256 |
| SOSRA | 0.002 | 1.00× | 0.0164 / 0.0235 | 0.0239 / 0.0373 | 0.0232 / 0.0271 |
| SOSRA | 0.005 | 2.49× | 0.0169 / 0.0237 | 0.0289 / 0.0356 | 0.0247 / 0.0285 |
| SOSRA | 0.01 | 4.95× | 0.0259 / 0.0291 | 0.0432 / 0.0442 | 0.0545 / 0.0519 |
| SOSRA | 0.02 | 9.79× | 0.0790 / 0.0717 | 0.1026 / 0.0913 | 0.1998 / 0.1781 |
| Heun | 0.002 | 1.70× | 0.0162 / 0.0236 | 0.0265 / 0.0396 | 0.0236 / 0.0266 |
| Heun | 0.005 | 4.23× | 0.0219 / 0.0268 | 0.0369 / 0.0416 | 0.0425 / 0.0380 |
| Heun | 0.01 | 8.38× | 0.0651 / 0.0592 | 0.0799 / 0.0754 | 0.1632 / 0.1424 |
| Euler | 0.002 | 2.56× | 0.1003 / 0.1029 | 0.1211 / 0.1284 | 0.2572 / 0.2519 |

Euler 对 action density 产生正偏差；较大步长的 Heun/SOSRA 主要产生负偏差。
这种模式与刚性的短波格点自由度的时间离散误差一致，而不是守恒量漂移。
所有稳定运行的逐配置 `M` 最大绝对漂移均小于 `1.6e-6`。

同一步长的热 GPU 成本为：

| 方法 | ms/step | 相对 SOSRA 每步 |
|---|---:|---:|
| SOSRA | 0.268 | 1.00 |
| Heun | 0.158 | 0.59 |
| Euler | 0.105 | 0.39 |

Heun 的收益来自把每步三次 drift 和四个 Gaussian link 场降为两次 drift
和两个 link 场。Euler 再降为一次 drift，但其有限时间偏差已抵消这一性能
价值。

## 解释边界

本测试覆盖两个实际初态分布、101 个物理时刻和几个对紫外误差敏感的实空间
统计量，足以否决明显有偏的候选。它仍不是 1024 维全场分布相等的证明，也
没有测模型训练后的 loss 或生成质量。若要把候选投入生产，还应使用相同
训练 target 做一次端到端验证，或者增加实空间 patch/block 统计与独立重复
实验。
