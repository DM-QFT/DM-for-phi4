# 二维周期反应扩散的 Particle U-Net 验证方案

## 1. 第一版目标与边界

学习固定物理时间间隔 `Δt = 10` 的条件坐标分布。使用同一套网络参数处理不同盒子尺寸、条件粒子数和目标粒子数。第一版只使用坐标 Gaussian diffusion，不引入删点、出生、合并或分裂的辅助生成过程。

**条件是完整的 `X0`，加噪对象是完整的 `X10`。** 每个训练事例的目标粒子数可以不同，但一次反向采样期间的目标粒子数 `M` 保持不变。因此，这一版学习的是给定 `M` 的坐标分布 `p(X10 | X0, N10=M)`，不包含未来粒子数分布 `P(N10 | X0)`。

## 2. 物理数据

- 空间为 `[0,L)²`，使用周期边界。粒子进行 Brownian 扩散和局部 `A ↔ 2A` 反应。
- 所有尺寸使用相同的 `D`、分支率、合并率、反应半径 `r`、产物位置规则和模拟时间步长。把这些设置写入配置文件。
- 训练尺寸为 `L/r = 16-64`，初始密度为 `n0*r² = 1`，对应初始粒子数 `16^2-64^2`。未来粒子数由真实模拟器决定，不强制固定。
- 先使用均匀随机初态，再加入团簇、空洞和长波密度调制，避免只在均匀平均密度上验证。
- 按独立物理轨迹或初态划分训练集和测试集。为部分测试初态生成多个独立未来事例，用于检查条件统计。

每个数据文件保存以下内容。不需要跨物理时间的粒子 ID 或粒子配对。

```text
x0:  float32[N, 2]    # 条件构型
x10: float32[M, 2]    # 真实未来构型
L:   float           # 周期几何元数据，不作为全局网络特征
trajectory_id        # 防止同一轨迹跨训练集和测试集
```

若尚无微观模拟器，可以先固定一个明确的反应核。例如，每粒子以速率 `λ` 在半径 `r` 圆盘内均匀产生一个新粒子，母粒子保留。每个距离小于 `r` 的无序粒子对以速率 `γ` 合并，随机保留其中一个。`D, λ, γ` 作为独立配置项，不随 `L` 改变。先检查模拟时间步长收敛，再生成训练数据。

## 3. 加噪与训练目标

对每个事例独立采样噪声尺度 `σ` 和标准 Gaussian 噪声。

```python
eps = randn_like(x10)
z = (x10 + sigma * eps) % L
pred = model(condition=x0, noisy=z, sigma=sigma, box=L)
loss_sample = ((pred - eps)**2).sum(dim=-1).mean()
loss = mean(loss_sample_over_batch)
```

- `pred.shape == (M, 2)`。同一事例的所有目标粒子使用同一个 `σ`。
- 保留实际采样的 `eps` 作为监督。不能用取模后的最小镜像位移重新计算噪声标签。
- 网络使用 `log(σ/r)` 的时间嵌入，各尺度都注入该嵌入。所有长度使用固定物理单位，不将距离除以 `L`。
- 均衡抽取不同尺寸。先对每个事例的粒子损失取平均，再对事例平均，避免大系统自动获得更大训练权重。
- 初始实验可对 `log σ` 均匀采样。噪声范围与反向采样参数单独记录并做收敛测试。

## 4. 网络结构

### 4.1 输入与局部计算

将 `X0` 和 `Z` 拼成带来源标记的节点集合。两类节点分别使用 `(1,0)` 和 `(0,1)` 标记，保留重合位置的不同粒子。网络最终只读取 `Z` 节点的输出。

所有邻域使用周期相对位移。

```python
dr = pos_j - pos_i
dr = dr - L * round(dr / L)
edge_exists = norm(dr) < radius
```

每个局部块使用共享参数进行消息传递。按节点类型区分条件信息和加噪信息，保留邻居求和与局部计数，允许 `Z` 节点之间交换信息。不要仅使用均值聚合或归一化 attention。

各层保留标量特征与少量二维向量特征。标量网络读取距离、计数、向量内积和时间嵌入。向量通过相对位移、向量通道线性组合及标量门控更新。最终用向量通道输出二维噪声预测。

### 4.2 三尺度 U-Net

以下为起始配置，半径均为固定物理长度。

| 层级 | 支撑点 | 消息半径 | 标量/向量通道 | 残差块数 |
|---|---|---|---|---|
| 细层 | 全部 `X0 ∪ Z` 节点 | `r` | `64 / 16` | 2 |
| 中层 | 局部粗支撑点 | `2r` | `128 / 32` | 2 |
| 粗层 | 更稀疏的局部支撑点 | `4r` | `256 / 64` | 2 |
| 中层解码 | 返回保存的中层位置 | `2r` | `128 / 32` | 2 |
| 细层解码 | 返回原始粒子位置 | `r` | `64 / 16` | 2 |

**第一版可用周期辅助支撑网格实现粗层。** 中层间距为 `r`，粗层间距为 `2r`，点数随面积增长。粒子到支撑点、支撑点之间、支撑点回到粒子的连接都限定在局部半径内。真实粒子坐标和输出仍然连续，辅助网格只承载隐藏特征。

下采样时，将每个细点的计数以归一化局部分配权重传给粗点，分别保存条件粒子和目标粒子的计数。上采样时局部插值，再与同尺度编码特征拼接形成 skip connection。

该辅助网格版本具有网格相位依赖，**不宣称严格的任意连续平移等变性**。训练时可随机平移辅助网格，并测量同一输入对网格相位的敏感性。它比全局 FPS 更便于检查严格的有限作用范围。纯点集粗化可以作为后续替换。

### 4.3 必须保留的实现约束

- `L` 只用于周期几何、支撑点构造和坐标取模，不作为 MLP 的全局标量输入。
- 通道数、物理半径和参数固定，节点数随输入和面积变化。不要把粗层压成固定长度的全局向量。
- 归一化仅在单个节点的通道内进行，不跨整张图或不同事例计算统计量。计数通道单独保留。
- 不使用全局 attention，不按全系统粒子数归一化局部聚合。
- batch 使用节点拼接和 `batch_id`，禁止跨事例连边，每个事例使用自己的 `L`。不需要粒子数 padding。
- 最初采用平滑截断核。上述最大单层半径为 `4r < L_min/2`，但多层网络的总感受野可以更大。

## 5. 反向生成

每次生成显式指定目标点数 `M`。先初始化 `M` 个周期均匀位置，然后沿同一个噪声日程去噪。所有尺寸共用网络参数与物理单位下的噪声范围。

均匀先验只在最高噪声端充分混匀时成立。针对第一版最大测试尺寸 `L/r=40`，可从统一的 `σ_max/r=40` 开始，`σ_min/r=10^-3` 作为起始截断。该选择不是任意体积下的保证，扩大测试盒子时必须重新检查先验误差与噪声范围。

对递减噪声网格 `σ_K > ... > σ_0 = σ_min`，可先实现 VE 反向 SDE 的以下离散更新。

```python
z = uniform_in_box(M, L)
for sigma_hi, sigma_lo in descending_noise_pairs:
    eps_hat = model(x0, z, sigma_hi, L)
    score = -eps_hat / sigma_hi
    dv = sigma_hi**2 - sigma_lo**2
    z = (z + dv * score + sqrt(dv) * randn_like(z)) % L
return z
```

每次更新后重新构建依赖 `Z` 的几何。先比较 `128, 256, 512` 个反向步及不同 `σ_min`，不要直接将有限步长误差归因于网络。这里输出的是最低噪声处的近似样本。

**测试时使用真实未来的 `M` 只能作为给定终态粒子数的诊断，必须标注为已知粒子数测试。** 这一版不构成未知未来粒子数的完整模拟器，也暂不将固定 `M` 的生成构型当作真实变粒子数动力学反复迭代。

## 6. 最小验证清单

1. **结构正确性**。同一模型同时接受不同 `(N,M,L)`，输出形状正确。重排输入后对应输出一致，batch 与逐样本计算一致。
2. **局域性**。保持辅助支撑点和随机量不变，修改某输出有效感受野之外的粒子，该输出不变。粗化、插值和归一化都纳入测试。
3. **几何与分辨率**。检查周期边界连续性、辅助网格相位敏感性，以及增大半径、深度和支撑分辨率后的结果。
4. **可解析极限**。先关闭反应验证独立 Brownian 传播，再启用反应。单粒子周期转移可直接与 wrapped Gaussian 比较。
5. **混合尺寸与外推**。
6. **物理统计**。使用相同粒子数条件和初态抽样规则，比较平均密度、区域粒子数、粒子对关联和密度 Fourier 模。均匀初态的平均密度不足以单独证明成功。

另保留一个使用相同局部块的单尺度 GNN 基线，以判断多尺度结构是否确有收益。

## 7. 两类实验不要混淆

**本文件的主实验是系统尺寸变化。** 相同局部物理与密度下，盒子和粒子数一起增大，同一个网络处理更多自由度。

**同一盒子内把代表点数从 32 改成 64，是另一项表示分辨率实验。** 未经重采样或权重设计，完整构型的坐标去噪训练不会自动保证这两种输出代表同一个密度。重建平均密度时可以使用每点权重 `E[N10 | X0]/M`，但还必须保证位置采样器学习了相应的粒子加权一点分布，不能只给本文件生成器的输出乘一个权重就假定成立。

## 8. 建议的代码拆分

```text
simulate.py       # 反应扩散数据与模拟步长检查
geometry.py       # 周期邻域、辅助支撑点、局部分配与插值
model.py          # Particle U-Net 与 noise head
train.py          # 可变长度 batch、混合尺寸训练
sample.py         # 指定 M 的坐标反向扩散
evaluate.py       # 对称性、局域性、条件统计与尺寸外推
config.yaml       # 统一记录物理参数、网络和噪声日程
```

执行顺序为 `几何单元测试 → Brownian 基准 → 单尺寸反应数据 → 混合尺寸训练 → 冻结参数的尺寸外推`。通过这些验证后，再决定加入真实粒子数生成，还是建立固定代表点数的加权表示模型。
