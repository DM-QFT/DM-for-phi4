# Model B 求解器的 HMC ground-truth 验证

测试日期：2026-07-18  
环境：Miyabi-G `mg0939`，NVIDIA GH200 120 GB，Julia 1.12.6，
CUDA.jl 6.2.0，StochasticDiffEq 7.1.1。

## 最终结论

对当前与 `DM/2Dphi4` HMC 数据严格匹配的 Model B，综合推荐：

1. **正式计算使用 fixed-step `SOSRA()`，`adaptive=false`。**
   - `dt=0.01`：默认的精度/速度平衡点；
   - `dt=0.005`：高精度；
   - `dt=0.02`：快速预跑，约 1% 场强误差和 1% 平衡作用量偏差；
   - 必须提供独立、具有同一守恒空间协方差的辅助过程 `Z`。
2. **adaptive `SOSRA()` 可以合法使用，但没有稳定地超过调好的 fixed step。**
   `tol=0.2, dt_initial=0.001, dtmax=0.02` 可作为初始瞬态很强或刚性变化时的保守方案；
   稳态生产仍选 fixed step。
3. **不要使用 `DRI1NM()`。** 它要求非混合对角/标量加性噪声；本问题的 drift 在格点间耦合，
   且散度噪声在空间上相关。实测它严重破坏总磁化并给出 O(1) 的分布偏差。
4. `SOSRA2()`、`SROCK2()` 和 `LambaEM()` 均未进入这组测试的误差--耗时 Pareto 前沿。
5. 谱空间 `ETD1` 值得继续开发，但当前原型还不能取代 SOSRA：其平衡偏差是一阶、优势随
   格点大小改变，且 `dealias=true` 会改变 HMC 目标作用量。若使用，必须关闭去混叠并另做
   动力学强误差验证。

这些结论对应

```text
T=1, kappa=0.2705, lambda=0.022, dx=gamma=1
```

不能把旧报告中 `T≈4.45`、势能 `-phi^2/2+phi^4/24` 的结果与本 HMC 基准混在一起。

## 为什么现有 HMC 可以作 ground truth

HMC 文件的作用量为

```math
S[\phi]=\sum_x\left[-2\kappa\sum_{\mu=1}^2\phi_x\phi_{x+\hat\mu}
 +(1-2\lambda)\phi_x^2+\lambda\phi_x^4\right],
\qquad P_{\rm HMC}\propto e^{-S}.
```

其变分为

```math
\frac{\delta S}{\delta\phi}
=-2\kappa\Delta\phi+
\left[2(1-2\lambda)-8\kappa\right]\phi+4\lambda\phi^3.
```

本次测试的 drift 与噪声严格使用

```math
d\phi=\Delta\frac{\delta S}{\delta\phi}\,dt+\sqrt{2}\,\nabla\cdot dW,
```

因此连续时间不变分布正是 `T=1` 的 HMC 分布。L=16 全部 10240 个 HMC 构型给出
Schwinger--Dyson 检查 `mean(phi * dS/dphi)=1.000036`，也支持温度和归一化匹配。
基准的 batched GPU kernel 还与 `ModelB.jl` 生产 kernel 做了同一随机场的逐点交叉检查：
drift 和链路噪声的最大差分别为 `7.6e-6` 与 `4.8e-7`（Float32 运算顺序舍入水平）。

Model B 会固定每条轨迹的总磁化，但这不妨碍使用完整 canonical HMC：canonical 分布是各个
固定磁化扇区的正确混合。测试从每个原始 HMC 构型分别起跑，并保留其自身磁化；精确动力学
应保持整个混合分布不变。**不能先对每个 HMC 构型减均值**，那不是正确的 `M=0` 条件分布。

HMC 数据位于 `../../2Dphi4/trainingdata/`，有
`kappa={0.26,0.2705,0.28}`、`L={8,16,32,64,128}`，每份 10240 个 Float64 构型。
文件没有保存完整的 warmup、seed、thinning 等生成元数据，所以误差按原链顺序用 64 个 block
估计，而不是假设 10240 个样本完全独立。

同成本比较最清楚：

## adaptive SOSRA

配置同 L=16、N=10240、`t=5`，`dt_initial=0.001, dtmax=0.02`：

| `abstol=reltol` | 平均 dt | accepted/rejected | wall / s | 相对作用量漂移 |
|---:|---:|---:|---:|---:|
| 0.5 | 0.01779 | 281 / 0 | 0.358 | -0.995% |
| 0.2 | 0.00752 | 665 / 0 | 0.841 | -0.099% |
| 0.1 | 0.00380 | 1316 / 0 | 1.659 | -0.133% |
| 0.05 | 0.00191 | 2623 / 0 | 3.343 | -0.010% |
| 0.02 | 0.000761 | 6567 / 0 | 8.396 | -0.049% |

adaptive 在形式上有效，而且 `tol=0.2` 的平衡误差很好；但：

- `tol=0.5` 与 fixed `dt=0.015` 成本相同（0.358 vs 0.354 s），作用量偏差却更大
  （0.995% vs 0.552%）；
- `tol=0.2` 的平均步长几乎等于 fixed 0.0075，却慢约 20%（0.841 vs 0.703 s）；两者的
  漂移都只在约 1--1.5 sigma 范围内，不能把随机中心值差异解释成稳健的算法优势；
- 局部 `abstol/reltol` 不直接控制场强误差或平衡观测量误差。

所以 adaptive 适合防止未知瞬态失稳，不是已调好稳态生产步长的首选。

## DRI1NM 为什么不能用

当前 StochasticDiffEq 文档把 `DRI1NM` 限定为

```text
du[k] = f_k(u[k]) dt + sigma[k] dW[k]
```

一类每个分量只依赖自身的 non-mixing diagonal 问题，或真正的单一标量加性噪声。本 SPDE 的
双调和/拉普拉斯 drift 显式耦合邻点，且 `div dW` 的各格点分量空间相关并具有严格零模。
`DRI1NM` 的内部弱随机变量不服从该守恒子空间；这解释了实测的 O(0.1--1) 磁化漂移。
调小 `dt` 或容差只会缩小但不会修复错误的噪声结构。

## 谱 ETD1 的筛选结果

关闭去混叠后的 ETD1 能精确积分线性 OU 部分，但显式处理三次项。本次 HMC 平稳性结果：

| L,N | dt | wall / s | 相对作用量漂移 | 最大磁化密度误差 |
|---|---:|---:|---:|---:|
| 16,10240 | 0.005 | 0.302 | +0.548% | 3.9e-6 |
| 16,10240 | 0.01 | 0.151 | +1.089% | 2.4e-6 |
| 64,512 | 0.005 | 0.241 | +0.696% | 1.1e-6 |
| 64,512 | 0.01 | 0.120 | +1.127% | 8.9e-7 |

它在 L=16 某些弱误差成本点略快于 SOSRA，但在 L=64，相近偏差的 SOSRA 0.02 更快
（0.189 vs ETD1 0.005 的 0.241 s）。此外当前尚无与 SOSRA 同一 Brownian path 的 ETD
动力学强误差比较。结论是“值得优化和继续验证”，不是当前默认选择。特别注意：现有
`ModelB_spectral.jl` 默认 `dealias=true`；这样不再以原始有限格点 HMC action 为不变分布。

## 适用边界

- 本报告验证的是 raw canonical HMC mixture 的平稳性。若最终物理问题严格要求 `M=0`，应生成
  zero-mode constrained HMC；不能把 canonical 样本逐个减均值冒充 ground truth。
- HMC 只给平衡分布，不给 Model-B 实时间动力学；动力学精度由共同 Brownian 路径的细步参考解验证。
- Float32 守恒误差随步数积累；正式长时间结果仍应记录每条轨迹的最大磁化漂移。
- `dx != 1` 时必须重新处理离散白噪声的体积归一化，本报告不覆盖该情形。
