# Model B 临界点附近 SPDE 求解器测试报告

> **模型区分：** 本报告测试旧 Hamiltonian
> `H=Σ[(grad phi)^2/2-phi^2/2+phi^4/24]` 与 `T≈4.45`。`DM/2Dphi4`
> HMC 数据对应另一个 `T=1` 的 `(kappa,lambda)` action；严格匹配的新验证见
> [`hmc_solver_report.md`](hmc_solver_report.md)。

测试日期：2026-07-17  
环境：Miyabi-G `mg0939`，NVIDIA GH200 120GB，Julia 1.12.6，CUDA.jl 6.2.0，
StochasticDiffEq 7.1.1。

## 结论

1. **综合推荐：定步长 `SOSRA()`，`adaptive=false`。** 必须提供与 `W` 独立、但具有同一
   空间协方差的守恒辅助过程 `Z`。当前离散（`dx=gamma=1`）下：
   - `dt=0.01`：精度与速度最均衡；
   - `dt=0.005`：高精度选择；
   - `dt=0.02`：快速预跑/低精度选择；
   - `dt=0.04`：L=256、T=4.45、t=10 的 10/10 次运行全部不稳定，不应使用。
2. **若不修改原始 `ModelB.jl`，只能可靠地使用定步长 `EM()`。** 建议正式结果用
   `dt<=0.0025` 做步长收敛，`dt=0.005` 只作为较快基线。
3. **禁止 `DRI1NM()`/`DRI1()`。** 它们破坏散度噪声的零模与空间协方差；这不是调小容差
   可以修复的问题。
4. `SOSRA2()`、`SROCK2()` 和 `LambaEM()` 在这组测试中均未进入误差--耗时 Pareto 前沿。
5. 若目标是大格点临界长时间动力学，下一步应实现离散谱空间 ETD/半隐式格式；本报告没有
   把尚未实现和验证的 ETD 纳入排名。

## 共同噪声精度测试

非线性 Model B：

```math
\partial_t\phi=\Delta[-\Delta\phi-\phi+\phi^3/6]+\sqrt{2T}\,\nabla\cdot\eta,
\qquad \bar\phi=0.
```

主测试使用 `T=4.45`、L=16、`t_end=2`、16 条路径；另测 `T=4.35/4.55`（各 8 条）和
L=32、T=4.45（8 条）。参考解为 `SOSRA dt=0.000625`。所有方法共享最细网格上的链路
Brownian path；粗步 `dW` 严格求和，SOSRA 的 `I_(1,0)` 也按组合公式严格嵌套。因此下面
是成对强误差，不是两条无关随机轨迹之差。该部分在 CPU Float64 上运行以隔离时间离散误差；
随后另用生产一致的 GPU Float32 路径检查吞吐、稳定性和守恒。

T=4.45、L=16 的末态相对场 RMSE（均值 +/- 路径标准误）：

| EM | 0.005 | 4.085% +/- 0.087% | 5.3e-16 | |

- `SOSRA dt=0.01` 与 `EM dt=0.005` 用时近似相同（0.321 vs 0.335 s），场误差约小 3.9 倍。

- 若目标约 4% 场误差，`SOSRA dt=0.02` 比 `EM dt=0.005` 快约 2.1 倍。

## SOSRA 自适应步长补充测试

修正后的守恒 `W/Z` 和 Brownian bridge 使 adaptive SOSRA 在形式上可用，但没有显示出
效率优势。L=256、T=4.45、`dt_initial=0.001`、`dtmax=0.02`、`t_end=1` 的两种子测试：

| abstol=reltol | 平均实际 dt | accepted steps | GPU wall time / s |
|---:|---:|---:|---:|
| 0.5 | 0.00671 | 149 | 0.070--0.073 |
| 0.2 | 0.00295 | 339 | 0.160--0.165 |
| 0.1 | 0.00151 | 661--662 | 0.310--0.315 |
| 0.05 | 0.000763 | 1310--1311 | 0.611--0.621 |
| 0.02 | 0.000304 | 3285--3289 | 1.61--2.11 |
| 0.01 | 0.000152 | 6596--6603 | 3.18--3.19 |

`t_end=10`、`tol=0.5` 的三次预热后测试平均 `dt=0.00783`，中位耗时 0.595 s；固定
`dt=0.01` 只需 0.321 s。自适应局部容差也不等于场误差或平衡统计误差。因此稳态临界生产
仍推荐 fixed SOSRA；自适应更适合初始瞬态或刚性随时间显著改变的情形。若必须使用，可从
`tol=0.5, dt_initial=0.001, dtmax=0.01` 开始，并与 fixed `dt=0.005/0.01` 做观测量收敛比较。

## 原生产文件的限制

- `ModelB.jl` 默认 `DRI1NM()`，不适用于当前相关守恒噪声。
- 原 Brownian bridge 是空函数；自适应或拒步算法不可信。
- 原噪声过程没有创建 SOSRA 所需的 `Z`。
- 噪声核把 `dx` 写死为 1；当前结论只适用于 `dx=gamma=1`。二维一般 `dx` 下还需处理
  链路白噪声的 `dx^(-d/2)` 归一化。
- 噪声 callback 忽略传入 RNG。`CUDA.seed!` 可复现单次运行，但不同算法/步长仍不能获得
  共同 Brownian path。
- `abstol/reltol` 对 fixed-step EM/SOSRA 不起作用。

测试 runner 已实现守恒 Gaussian bridge 与可选 `Z`。推荐调用形式为：

```julia
sol = modelB_2d_SDE_prob(
    u0 = uini,
    T = 4.45f0,
    solver = SOSRA(),
    with_Z = true,
    dt = 0.01f0,
    adaptive = false,
    save_end = true,
)
```
